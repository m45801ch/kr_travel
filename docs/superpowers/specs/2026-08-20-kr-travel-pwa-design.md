# 韓國旅遊 PWA 設計規格

日期：2026-08-20
狀態：設計已確認，待建立實作計畫

## 1. 目標與範圍

建立一個手機優先的單人旅遊規劃 PWA，第一版以本機儲存為主，支援離線查看與編輯，並預留未來多趟旅程與雲端同步的資料邊界。

底部導航固定為五個功能：行程、記帳、購物、準備、設置。參考截圖只作為視覺方向；截圖中的預約、成員等額外導航不納入底部導航。旅伴資料仍會存在於記帳分帳與清單指派流程中。

第一版不包含登入、雲端同步、內嵌 Google 地圖、多人即時協作或 App Store／Google Play 上架。

## 2. 使用者需求

- 建立一趟旅程，資料模型預留未來多趟旅程切換。
- 依日期查看每日行程、目的地天氣與活動時間軸。
- 新增、編輯、排序、刪除行程活動。
- 活動地點儲存名稱與地址，點擊後開啟 Google Maps 導航。
- 自動取得目的地天氣，失敗時顯示上次快取資料。
- 設定總預算、記錄支出、分類統計與外幣換算。
- 支援旅伴、平均分帳、自訂金額／比例及結算結果。
- 管理購物與行前準備項目，支援分類、照片、備註、期限、重要程度與旅伴指派。
- 讓旅程、每日行程、清單與旅伴選擇原創韓系旅遊插畫、韓服、街頭服裝與配件。
- 支援主題色、字體大小、深色模式、特效開關與資料匯出／匯入。

## 3. 技術架構

採用 React + Vite + TypeScript 的本機優先架構：

```text
React UI
  -> 功能模組與操作邏輯
  -> Repository 資料存取層
  -> IndexedDB 本機資料庫
```

外部服務獨立封裝：

- 天氣：Open-Meteo API，不需要 API Key。
- 地圖：產生 Google Maps 搜尋／導航 URL，不嵌入地圖。
- PWA：Web App Manifest、Service Worker、離線快取。

Repository 層隔離 IndexedDB 細節，未來可替換為雲端同步實作，而不需重寫主要頁面。

## 4. 頁面與功能

### 行程

畫面由旅程標題／目的地、日期橫向選擇器、天氣卡片、每日摘要、活動時間軸與新增按鈕組成。活動欄位包含日期、時間、類型、名稱、地址、Google Maps URL、備註、提醒時間、排序位置與 illustrationId。

### 記帳

顯示總預算、已支出、剩餘預算、匯率換算、分類統計與支出列表。支出可設定日期、金額、幣別、匯率、類別、付款人、共同分攤旅伴、平均／自訂分帳方式與備註。金額以最小貨幣單位整數儲存，避免浮點數誤差。

### 購物

顯示待購買與已購買數量，支援分類篩選與狀態切換。項目包含名稱、照片、分類、重要程度、備註、購買地點、期限、指派旅伴、完成狀態與 illustrationId。

### 準備

依行前準備、證件／簽證、保險、行李、其他分組，顯示完成數量與進度。項目支援名稱、重要程度、截止日期、指派旅伴、備註、完成狀態與 illustrationId。

### 設置

提供主題顏色、字體大小、深色模式、飄落特效、預設幣別、旅程資料管理、資料匯出／匯入、PWA 安裝說明與清除本機資料。

## 5. 資料模型

```text
Trip
|- TripDay
|  `- Activity
|- Member
|- Expense
|  `- ExpenseSplit
|- ShoppingItem
|- PrepItem
`- WeatherCache
```

Trip 儲存旅程名稱、目的地、日期、預設幣別、預算、封面圖案與主題色。TripDay 儲存日期、城市、每日標題、摘要與住宿資訊。Activity 儲存活動詳細資料與地圖連結。

ExpenseSplit 儲存旅伴、分攤金額／比例與結清狀態。ShoppingItem 與 PrepItem 共用清單欄位，但以 type 區分功能。Member 儲存姓名、頭像圖案 ID、顏色與備註。WeatherCache 依目的地、日期與更新時間保存天氣結果。

韓系插畫以 illustrationId 儲存，例如 hanbok-woman、streetwear-man、airport-travel、shopping-bag、korean-house。隨網站打包的插畫保持離線可用；使用者上傳的購物照片壓縮後存入 IndexedDB。

## 6. PWA 與離線策略

網站部署至 HTTPS 後可由手機瀏覽器加入主畫面，不需上架商店。Android 使用瀏覽器的安裝選項；iPhone 使用 Safari 的「加入主畫面」。

離線時可查看／編輯行程、記帳、購物、準備清單，切換圖案與匯出備份。更新天氣、開啟 Google Maps 與首次載入網站需要網路。網站程式、韓系插畫與必要資源由 Service Worker 快取；天氣保存最後成功資料與更新時間。

本機資料只存在該裝置的瀏覽器。清除瀏覽器資料可能造成資料遺失，因此 MVP 必須提供 JSON 匯出／匯入備份。

## 7. 視覺與互動規格

採用奶油色背景、粉色主色、大圓角卡片、柔和陰影與手繪感韓系旅遊插畫。支援粉、藍、綠、紫、黃等主題色。所有插畫使用原創風格，不直接複製參考圖角色或圖片。

共用互動包含固定底部導航、右下角情境式新增按鈕、底部抽屜／全螢幕表單、卡片三點選單、刪除二次確認與未儲存離開提示。介面需符合手機安全區域，並支援字體大小與深色模式。

圖案選擇器提供目前預覽、人物／服裝／配件／背景分類、圖案網格、隨機選擇、重設與套用。

## 8. 開發順序

1. 建立 React、資料層、手機 Layout、五個導航與 PWA 基礎。
2. 完成行程、日期、天氣、活動表單與 Google Maps 連結。
3. 完成預算、支出、匯率、旅伴與分帳結算。
4. 完成購物、準備、照片、期限、指派與插畫選擇器。
5. 完成設置、備份、離線驗證、PWA 安裝與 HTTPS 部署。

## 9. 驗收條件

- 可在手機瀏覽器開啟並加入主畫面。
- 無網路時可查看與編輯本機資料。
- 可建立每日行程並從地點開啟 Google Maps。
- 可取得並快取目的地天氣。
- 可記錄外幣支出並完成平均／自訂分帳。
- 可管理購物與準備清單及進度。
- 可為旅程、人物與項目選擇韓系圖案。
- 可匯出與匯入資料備份。
- 可切換主題色、深色模式與字體大小。
- 主要功能在手機窄螢幕上不出現水平溢位，表單與按鈕可操作。
