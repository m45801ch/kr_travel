# 旅行應急備份設計

## 目標

讓使用者在遠端服務故障、換機或清除瀏覽器資料時，仍能閱讀與還原旅程資料。

## 設計

- 保留現有 JSON 備份，作為 APP 還原格式。
- 新增單一操作的「旅行應急包」，輸出人類可讀 HTML、CSV 與 JSON。
- HTML 內嵌行程照片、旅伴照片與 LINE QR Code，開啟時不依賴網路。
- HTML 包含行程、購物、準備、旅伴與記帳資料；CSV 提供試算表相容的平面資料。
- 所有資料直接讀取本機 IndexedDB，不經過伺服器。
- 匯出失敗時顯示錯誤訊息，不影響本機資料。

## 驗證

- 測試 HTML 包含主要資料與嵌入圖片。
- 測試 CSV 可正確跳脫逗號、換行與引號。
- 保留既有 JSON 匯入／匯出測試。
